# T18 生产资产来源与导出

本目录保留本轮4场景与5肖像的9份被选中原稿，另保留1份登仙台编辑输入，不是回取的两组历史高清原件，也没有放大/切片320预览。用户[原始目标](../../goal-1/input.md)与[实施计划](../../goal-1/plan.md)授权本项目制作和使用这些资产。使用内置image_gen；实际工具未返回模型名，不猜测模型/版本。未使用外部照片、字体文件、音乐或参考仓库资产。

完整逐资产提示词见[receipts/prompts.json](receipts/prompts.json)，每张对应receipt保留实际工具output_hint、默认原路径、复制事实与hash。原PNG从工具保存位置逐字节复制，默认原稿留存；不把生成成功视为T25风格/真人认可。主角/NPC服饰与外貌属于视觉提案，不新增境界、师徒年数、交情或身世事实。

## 实际规格

工具返回场景1672×941 RGB PNG、肖像1254×1254 RGBA PNG；实际值与原先建议2560×1440/1024×1024分别登记。场景运行版1536×865 WebP，肖像512×512 alpha WebP；不放大场景假装达到建议1920/2560。当前最大中央栏低于源图宽，实际四尺寸裁切另以截图检查。实际像素不是最终retina/性能或用户质量承诺。

使用`cwebp -quiet -q 84 -m 6 -resize 1536 0 -metadata none`（场景）或`-resize 512 512`（肖像）编码；保留真实alpha，不重画/扣除/替换内容。原稿主体alpha主要为252—253，运行版0—254；不将原稿软蒙版强行归一为255。透明背景与近不透明主体分别由实际像素检查，不能以“有alpha通道”代替解码检查。`art/tools/export_production.py`仅重导出已存在的原稿并刷新机器事实，不生成新图或自动提升技术审阅状态。单张场景≤500,000字节、肖像≤80,000字节是静态预算，首屏性能由T20实际测量。

登仙台先生成云台，再以同一原稿编辑中式牌坊和真实闭合双门；前版只作编辑输入保留，不增加活动母版。开启光面和雷光为原生叠层，仅按已提交Game的真实阶段出现；图片失效则回退到原生中式门。门洞/整座门的源像素坐标与图像hash绑定，叠层viewport匹配同一cover裁切。聚落母版以洞府/宗门/坊市的不同裁切、标题与内容区分；不把多张拼贴当作额外母版。图片文字/数值/按钮均由DOM负责。
