# 界面重排原型

这是0012设计合同的可点击布局参考，不是正式游戏。八个入口、单一详情页、炼丹安排草案、跨页活动条和真实显示计时在本地演示；示例数字不写入存档，不发放奖励。全部目录/后续条件等在原型中只展示结构，不能拿它代替正式玩法覆盖。

源文件为index.html、stage.css和stage.js。绘画复用asset-references.json所列11份现有资产；没有新生成素材。

本轮可打开 http://127.0.0.1:56885/ 。服务器使用既有scripts/candidate/serve.py，只服务artifacts/goal-3/u8-a/hierarchy-prototype-preview中的这三个文件和白名单资产，绑定127.0.0.1，不暴露仓库目录。正式56884没有被替换。

该原型按固定1440×900桌面核验；Codex窄侧栏660×718的偶然打开记录中出现挤压，临时标签已关闭，改以完整桌面图讨论方案。此观察和原图保留，不算兼容验收，也没有为此新增响应式或分辨率测试。需要试交互时使用完整桌面窗口。

重建预览时将三文件复制到独立目录，再按asset-references.json的source→path复制图片，使用既有serve.py的--directory及--port参数。不要用仓库根作为HTTP目录。

在依赖已安装且56885原型服务已启动时，从仓库根运行：

```sh
rtk proxy node goal-3/design/stage-prototype/verify.cjs
```

检查固定1440×900单Chromium的八入口/命中/无滚动、每页至多一个主要决策、编辑安排/跨页/暂停/停止、只读目标跳转与无浏览器存档写入。原型通过不是正式读秒/原子保存/成长平衡或真人美术验收，所有兼容测试仍暂停。
