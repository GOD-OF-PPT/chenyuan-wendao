没有新增Game字段/版本或失败历史。只有当前与上一提交同run、revision相邻、上一档确有天劫战斗、当前回洞府，才能显示刚结束的真实挑战；直接显示已保存的手记原因，不靠解析人类文本判断战败。匹配并验证的入场CP存在、月份相同且试炼无物资增加时才报告本轮库存差值耗物，不将净灵力变化当毛消耗。缺CP累计未知，当前库存照实显示。继续行动后即时摘要不再冒充永久账本，原手记保留。
