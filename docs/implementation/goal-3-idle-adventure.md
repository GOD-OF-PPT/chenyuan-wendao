## 实际行为

地点与敌人先只读选择，确认后才接受有限安排。行旅6秒抵达一次，不扣游戏月，不接取材、采购、研习或开战；遭遇每次30秒、正式1游戏月；斗法每正式回合3秒。默认一场、最多41个动作、1游戏月预算、余寿保留1、累计灵力480、各最多当前持有的1枚恢复丹。以上为未平衡初值，正式资源/技能/法宝/敌人规则保持，不证明长期成长速度合适。

剑意/符印门槛、招式顺序、重击应对、用药阈值/累计上限/库存保留和危险暂停/撤退可预选。费用按真实gross累计，回灵不重置灵力预算，收入不重置其他授权。普通胜利才发战利品；天劫只执行已存在的当前关，关末停下，问心、后续关及收卷仍由玩家决定。手动接管先停旧周期，再独立安排七种正式单步；暂停保留战局，撤退才扣8气血（最低1）、回洞府并清除本轮天劫。

复用既有九敌/场景、活动时钟、双时钟握手和原子仓库。v6以原始与当前决定Game的固定快照派生下一招，并经完整正式resolve证明当前周期。DB8保留旧Game、v1—v5活动、配置proof、检查点、归档和历史回执，关闭旧7连接；新普通短TRAVEL/ENCOUNTER/BATTLE被拒，合法旧回执优先重放。Game/内容/数值版本不改，刷新与离线不补发。

战场保留敌画、双方状态、真实意图/原始伤害、下一招及原因；开始接受后回到战局，原安排只读回填不覆盖草案。危险停手给手动服丹/撤退入口。当前活动在功能页保持，侧栏摘要与完整累计/逐次回执分开，回执两列分页且不被下一周期抢回首页。新回合只在战场使用实际保存结果的打击/净变化反馈，切页撤下演出；本地周期身份补绑只给表现副本，公共记录仍脱敏，不产生奖励。

旅行后查看意图绑定活动/人生/导航/外部同步；真实抵达并保存后只恢复原草案。暂停、外部接管、失败或后续导航不能由旧回调抢页；提交中暂停不回退已提交抵达。旧8份修改及5个矩阵工具、用户档、原输入/v0.3和旧证据/冻结均保留。
