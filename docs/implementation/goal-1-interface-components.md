## 实现

沿[已认可三栏](../decisions/0001-approved-baseline.md)保留左角色、中央场景/实际事件与操作、右目标/人物记录、四个底部入口；1280、1440、1920桌面均保留三栏，窄平板重排，390手机按地点/保存→中央事件及操作→目标→可展开角色排列。暖纸/青黛/旧金，正文18px，费用与禁用原因从10—12px提高到至少14px；按钮保留文字、边框与真实状态。肖像目前仍用印记，T18制作五张同风格头肩像。

`CharacterPanel`读取Game和共享LifeOverview：角色、境界、气血灵力、修为、年龄寿限、灵石、实际修法配装。飞升只保留封卷值，不显示虚构上界上限。原生details查看不改档；战斗中另在操作区显示当前己方气血/灵力，手机不必滚到角色卡才能决策。首次无战斗日志不显示空框。

`ScenePanel`与纯`scenePresentation`从实际地点和gamePhase派生四母版键/六地点语汇。洞府、宗门、坊市以洞口/檐楼/棚铺区分；古境碑石；天门准备/问心closed、三关storm、三关完成或ascended才opened。SVG只绘无字装饰，标题/叙述/姓名/数值/按钮全为DOM。T16的带字320预览不再加载；public历史副本保留原hash供核对。原生山云不是半写实生产图，四场景图片在T18单独交付；没有加载plannedPath或假装缺失高清原件已取得。

`PrimaryNav`只发出页面选择，App仍用原selectTab增加navigationRevision；晚到旅行/来源回调不能覆盖较新的查看意图。全部行为与确认/重试/取消复用原Store、共享preview与原子持久化，不新设规则/存档写入或动画结算。Game、版本、数值、依赖锁、v0.3正文和input/plan保留。
