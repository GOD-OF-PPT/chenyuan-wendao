# M1 首境界经济规则原型

状态：首批规则代码与本地验证。不是可玩的网页、不是完成的 M1，也不是完整 Demo。当前工程从 `mortal` 到 `qi` 再到 `foundation`，后续突破明确返回 CONTENT_BOUNDARY，不用终局文案冒充飞升。

## 交付

- src/content/m1.ts：境界、物品、稳定来源、配方/价格、行动、加成上限六类局部配置。version 为 m1-economic-slice.1，balanceVersion 为 m1-unbalanced.1，数值均为未平衡初值。
- src/game/engine.ts：纯 TypeScript 规则入口；校验指令、状态、地点、资源、修为；一次行动要么产生完整候选结果，要么拒绝，不修改输入。
- src/game/session.ts：仅用于验证的内存会话适配器；commandId 去重、runId 检查、expectedRevision 检查、提交失败不发布。**这不是持久化实现，进程退出不保留状态和回执。**
- tests/engine.test.mjs：65 条自动测试。
- scripts/replay.mjs：三个开场选择 × 炼丹/买丹两条确定经济路线回放。
- .github/workflows/core.yml：只读 CI，类型检查、规则测试、回放与文档子集校验；不部署、不发布。

## 实际规则

开场赠药/交易/离开分别扣除物资或记录选择，不赠送修为和境界。凡人通过基础吐纳及确认引气进入炼气，不需要突破丹；炼气至筑基则同时要求 1000 修为与一枚筑基丹，并真实消耗丹药。

炼丹在洞府检查材料、灵石和游戏耗时；商店采购与出售正确变更库存。筑基丹不可误卖。妖核可以通过宗门确定委托获得，也可用稳定杂务获取灵石后购买。恢复无需灵石和丹药，但消耗游戏年月；因此常规资源不足不会卡死。

批量修炼在修为满、灵石不足或寿元余量不足时停止；采集可设置库存目标并自动停止。单次批量提交只推进一次 revision，回执包含实际执行步骤与净变化。所有时间均为游戏内成本，规则不读取现实时间，也不设置几分钟突破。

## 本地验证（2026-10-13）

环境：Node.js v22.16.0、TypeScript 5.8.3。

| 验证 | 结果 |
| --- | --- |
| npm run typecheck | 通过（使用环境中已安装的 TypeScript 5.8.3） |
| npm test | 65/65 通过，0 失败/跳过 |
| npm run replay | 六条经济路线均达筑基且扣除筑基丹 |
| npm ci | 本地网络获取超时，离线缓存没有所需包；未宣称本地干净安装成功 |
| GitHub CI | 提供工作流，远端结论以对应提交的 Actions 为准，不能由本地测试推断 |
| 网页构建/浏览器/IndexedDB/真人测试 | 未实现或未执行 |

回放不是剑修/符修战斗路线验收，也不是全境界可达性验收。三种开场在当前经济原型中的后续结果相同是因果回响与战斗尚未接入，不能据此认为各流派已平衡。

示例路线结果（游戏月份，不是现实分钟）：自行炼丹到筑基为 32 游戏月、剩 20 灵石；购买成丹为 28 游戏月、剩 0 灵石。这只是当前配置与脚本策略的结果，不是最优解或玩家时长目标。

## 运行

安装 Node.js 22.16 或更新版本，在仓库根目录执行：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run replay
```

规则测试和回放使用 Node 内置测试器与类型剥离，未安装依赖时也可直接执行 `npm test` / `npm run replay`；类型检查需 TypeScript。这里没有 `npm run dev`，不要把无界面规则原型描述为可玩程序。

## 与最终契约的边界

1. 当前 State 是经济切片，暂未引入 GameState 的战斗、NPC 列表、完整事件调度、装备及数据库字段；不覆盖设计基线，不承诺此原型快照可作为正式存档。
2. parseSnapshot 只校验经济状态；MemorySession 的回执仅在当前进程有效。后续 IndexedDB 必须将状态和回执放进同一事务，并完成并发和跨标签页验证。
3. 寿元边界现在只阻止继续消费时间，未实现寿尽生平和检查点恢复。
4. 交易与旅行未配置游戏耗时；宗门护送是确定资源来源，没有伪称战斗实现。后续价格、风险与寿元平衡需要重新测试。
5. 当前只有参数表，不是完整六张策划工作表或全境界平衡。数值与内容扩充需要新版本及迁移决策。
6. 两流派战斗、正式古风主界面、浏览器持久化、后续境界和因果终局仍在待办。高清美术原件上传也尚未完成。
