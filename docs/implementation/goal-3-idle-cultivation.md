# Goal3 U2-I：在线周期修炼

2026-10-20，Asia/Shanghai。本轮承接[全玩法准则](../decisions/0006-idle-gameplay-interaction-rules.md)，只交付共享持久活动与修炼首条闭环。原话、实施前参数、验证及回滚见[Goal3计划](../../goal-3/plan.md)与[任务](../../goal-3/tasks.md)。其他24类行动尚未放置化，整体美术、完整玩法、长期平衡与用户验收继续；页面兼容开发及测试保持暂停。

## 玩家现在可以做什么

在洞府点击“开始自然吐纳”，每轮读秒结束自动积累、保存并开始下一轮，无需逐轮点击或领奖。主舞台保留人物、场景、实际读秒、已完成轮数、累计修为与支出；查看丹炉等功能时，侧栏继续显示当前修炼和暂停入口。普通周期不弹大成功横幅、不抢焦点。

“修行设置”可选择自然或灵石辅助、圆满/有限轮数目标，辅助可展开累计预算与灵石保留量。开始前按正式单周期规则预览实际能完成的轮数、收益、费用与预计停止原因。累计支出不被收入回补抵消；达到次数、修为上限、预算/保留线或寿元边界即停，不暗中购买、旅行、切活动或突破。停止后回响保留原因与累计成果，刷新仍可查看。

周期为未平衡初值：凡人30秒、炼气60秒、筑基90秒、金丹120秒、元婴180秒、化神240秒。每周期沿用正式修为、灵石、功法效果及游戏月成本；没有改变境界/物品数值或承诺通关时间。默认自然修炼至圆满、最多50轮、灵石预算0；辅助费用和授权上限明确可见。

本轮只支持在线执行。关闭或刷新保留已提交成果和安排，需要主动继续；未完成周期重新完整计时，不补发离线收益。隐藏页面回调迟到最多完成当前一个周期，下一轮从实际保存后重新等待，不追赶多轮。暂停立即取消本地等待；保存中的周期依事务边界完成后再持久暂停，不把尚未保存说成已暂停。

## 规则与保存边界

纯活动模型独立于Vue，活动保存计划、目标、完成量、累计成本、归属、代际、稳定单周期指令与停止原因。时钟只触发核验，实际收益仍由正式`CULTIVATE count=1`产生。普通存档写入口拒绝短批次修炼绕过；运行活动时其他Game写入须先暂停，查看与导航即时可用。

Game、previous、周期回执、活动下一状态同一IndexedDB事务提交，完成后才展示成功。失败停止自动推进，同一命令重试；回复丢失重放已保存结果，不再发收益。刷新同事务读取Game与活动；暂停/继续、旧回调、跨页接管、替换人生、坏记录和重复命令均受身份与版本校验。不同人生的活动不能接续，显式新建/导入/恢复/迁移保留归档后清除旧活动。

数据库v3升至v4，Game格式与内容/数值版本不变；真实旧Game、资源、回执与检查点保持。旧连接收到versionchange后关闭。回滚须保留v4读取和原件，只停止调度或回退界面；不能降数据库或直接把旧v3程序切回给已升级的档。

## 验证、发现与修正

本轮只在固定1440×900、单一Chromium检查实际改动。最终结果、源与运行文件绑定见[证据](../../goal-3/evidence/u2-i/verification.json)。422项核心规则/时钟检查、16项真实IndexedDB与Store检查、8项实际页面检查通过；包含一条真实30秒墙钟周期。资产正负例、库存守卫、根/Vue类型与生产构建另行核验。虚拟时钟用于长流程规则，不能证明实际成长节奏或趣味。

覆盖截止前零收益、连续逐轮积累、费用/预算/保留线、次数与上限停止、暂停与提交竞态、配额/中止回滚、丢回复同命令重试、刷新无离线补发、跨页归属、换人生与v3记录保留。相关指引也更新为“查看时在线活动继续，改做行动先暂停”，避免旧文案误导。

在`web`目录先执行`npm run build`，再分别运行`node node_modules/@playwright/test/cli.js test --config playwright.idle.config.ts`与`node node_modules/@playwright/test/cli.js test --config playwright.idle-persistence.config.ts`可复现本项定向检查。两个配置只声明1440×900 Chromium，不调用原三浏览器/性能矩阵；记录分别输出到被忽略的`web/idle-report`，失败截图/trace仍保留。Node要求沿用项目≥22.16，不新增依赖。

首轮跨页用例错误假定Playwright时钟按页隔离，按已安装实现确认它属于BrowserContext后，改为核对两页同钟下只有新owner单一周期回执；实际收益/完整Game断言保留。新增人物画曾受AssetImage内部相对定位影响、挤压并遮挡方式按钮，改为独立绝对定位容器后真实点击通过。交叉审查还修正旧回执重演标记、同Store重新连接的继续入口、开始/提交过程暂停的等待边界，以及自动停止原因消失。最终停止摘要与刷新后保留已加入页面断言；“末轮结算”只指向当前活动同人生、同修订的修炼结果。

未运行跨浏览器、移动、响应式、分辨率/字号缩放或环境/性能矩阵；未放宽旧预算/超时、删除旧失败或把加速夹具当正常玩法。Vite仍提示主JS块超过500kB，阈值未放宽；当前包约7MB，不代表性能验收完成。未做最终干净候选重建、全玩法矩阵、平衡或真人验收。保留在途CI/性能文件与历史报告，不推送触发暂停中的旧CI。

复用现有正式规则、存档、绘画、Playwright与资产工具，没有新造重复Skill或自动化。局部检查通过不反驳用户关于整体游戏感和流程的负面反馈。下一独立项是U3采集/委托的目标、预算、持续执行与专属交互，随后U4及当前授权范围的全面检查。
