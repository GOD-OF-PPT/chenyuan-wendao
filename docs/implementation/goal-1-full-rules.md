## 新增可执行检查

`npm run check:content`从实际TypeScript目录读取配置，校验7境界状态、6地点、14物品、16可重复来源、7配方、12功法、4法宝、9敌人、35配置事件（加开场共36）。

检查覆盖：安全整数与正成本时间、引用、境界顺序、来源地点与物品门槛、当前境界确定材料与货币来源、炼制/采购两种突破准备、突破物禁售、默认修法与固定三关依赖、事件前置缺失/循环/未来境界、选项身份、直接和连锁买入—炼制—出售获利。校验接受的来源图不计随机奖励或一次性赠品，不以期望掉落支撑必需物。

该检查是有限配置审计，不是任意JSON的运行时解析器，也不是所有行动序列的可达性证明。它核验解锁与稳定供给；寿元总预算、净收支和策略质量须由真实回放及后续T10验证。当前效果按ID分派，校验显式登记现有身份；T03要明确可复用效果的扩展契约，不能只增加配置就宣称已实现新机制。

`npm run replay:full`运行3开场×2修法×2筹备×2结尾共24条正常指令序列，无必需盟友，不直接发资源/改境界。输出版本、行动数、游戏月、剩余灵石、胜场与行动序列SHA-256。测试驱动器复用同一策略，因此不能把回放和测试数量相加当独立玩家样本。

两项命令已加入规则CI与网页CI，失败直接阻断；既有首境界回放保留。
