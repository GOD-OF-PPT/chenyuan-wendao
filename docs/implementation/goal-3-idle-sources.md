## 玩法与交互

16个正式来源保持原有地点、境界、确定产出和游戏月成本。玩家在历练的“采集/委托”选择资源点或委托，再安排有限轮数或物资/灵石库存目标；左侧保留实际地点绘画，右侧显示每轮产出与成本、当前选择和一个主要安排按钮。全部来源分页可查，选择来源/查看说明不扣费、不旅行、不发奖励。

默认5轮、累计预算5倍单轮游戏月、余寿保留1月；可选择1—50轮或库存目标及最大轮数，并展开累计月预算与余寿线。预览真实可完成轮数、产出和预计停止原因；最后完整一轮可能略超库存目标。每轮周期为正式单轮游戏月×30秒，即30—180秒，属于未平衡初值，不是已认可的成长用时。

开始后无需逐轮点击或领奖，真实读秒、单轮原子保存，再开始下一轮。修为圆满后材料来源仍继续；宗门杂务修为收益为0，仍按实际获得灵石。月预算只按实际消耗累计，不用收入抵消；目标达标、轮数、预算、余寿、容量或合法状态边界停止，保留实际原因与累计材料/灵石/月数。不会自动破境、旅行、采购或切换活动。

查看其他功能时仍显示来源、读秒、目标、成果与暂停。刷新/关闭不补发离线收益，主动继续重新等待完整周期；后台迟到回调只核验当前一轮。查看已保存安排会加载原轮数、目标、月预算与余寿线，编辑后需明确重新安排。运行中历练的旅行、采购与挑战禁用，并说明先暂停；只读导航与来源选择仍可用。

## 模型与保存

Game、previous、周期回执和下一活动状态同事务保存，完成后展示成果；失败中断自动执行，同意图重试与丢回复重放不再奖励。回执严格核对来源、目标、归属、代际与稳定指令。暂停、提交竞态、刷新、多页接管、换人生和损坏记录沿用共享保护。
