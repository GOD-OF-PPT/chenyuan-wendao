## 依据与实施方案

遵循[v0.3实施计划试玩记录](../v0.3/02_实施计划.md)、[状态契约](../v0.3/03_数据与状态契约.md)与[验收清单](../v0.3/04_验收清单.md)。记录新局、正常选择/行动、战斗结果、境界、错误、结局和重玩；每条有事件/会话ID、相对会话时间、人生/指令/版本、来源消耗与实际行动数，突破尝试附真实预览缺口。当前确定性引擎没有seed字段，记录seed=null并说明，不伪造随机来源。现实时间只供分析，不传入Game规则。

新增独立本地数据区保存显示偏好与必要试玩事件，不修改Game字段或主存档DB结构。字号/降低动效为浏览器偏好，现有目标追踪继续按runId隔离。游戏事务成功后通过隐私投影观察口异步记录；不等待记录I/O、不重复结算，不让观察器异常改变存档成功状态。回执重放去重并标记观察重放；继续原档、导入、新局、主动重开与完整恢复分别标识，不把关闭网页当作失败。

不记录道号、完整存档、错误原文、设备指纹、自由输入或墙上日期时间；非标准UUID来源标识留空并注明脱敏。只使用本机IndexedDB，不新增上传/请求接口。默认本地必要记录，欢迎与设置明确告知，可关闭、清空；导出先预览范围并由用户点击下载，不是存档且不能用于恢复。记录限制最近1000条/约1MB，超出时保留可见移除计数；存储失败显示仅本页/缺失状态，不谎称已保存，不覆盖未知旧数据。

本地设置写入校验独立epoch/commandId/expectedRevision，事件追加校验采集时epoch/控制revision并去重，清空/关闭采集挡住旧排队记录；本地事务complete后才公布持久化成功。跨页设置冲突重读，不覆盖后来选择。错误、坏数据、未知版本、升级关闭和配额失败均保持Game独立；记录只是尽力观察，不作为事实唯一依据。
