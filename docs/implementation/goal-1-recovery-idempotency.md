- restoreCheckpoint在一个事务中校验最新当前档/检查点/归属，替换完整准备快照、生成新runId、保存previous、清理旧回执并保留可重复使用的检查点。

- 所有写入入口用Promise拒绝。配额、存储拒绝、连接关闭、abort明确失败；只读exportRaw在open失败/未知新版本时仍能备份原件，缺库不创建。备份编码不伪装正常Game，不能无损表示的结构化值拒绝而不静默丢弃。
