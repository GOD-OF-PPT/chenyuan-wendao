## 收卷与恢复

| 状态 | 实际行为 |
| --- | --- |
| 主动归隐 | 沿用RETIRE；不扣剩余月或物资，不标为寿尽 |
| 寿元边界 | 普通耗时批次留出最后1月，只扣实际执行步；年龄/余寿显示到月 |
| 确认寿尽 | 只有最后1游戏月可确认，END_LIFE精确消耗1月并达到当前境界寿限 |
| 未决/战斗/试炼 | 生平可读，不能借收卷绕过当前状态 |
| 确认期间进度变化 | 固定预览commandId/runId/revision，页面提示过期，后台亦拒绝旧身份/版本 |
| 事务失败 | 不展示已结束，原活动人生/最后一月保留；同意图重试只结算一次 |
| 失败后继续此生 | 丢弃匹配收卷指令的重试，不从全局入口误重放；不误删其他动作意图 |
| 已有检查点 | 完整准备状态、物品、年月与人物记录一同回退，新run，检查点可再次恢复 |
| 没有检查点 | 明确说明；可导出好档/生平，不能从缺失历史补造快照 |

确认窗展示预览年龄/境界和明确后果；取消或Escape不写Game，提交中不以取消假装事务撤回。寿尽不使用现实倒计时，余寿提示不强迫结束；物资/修为已齐时仍可核对合法突破条件。
