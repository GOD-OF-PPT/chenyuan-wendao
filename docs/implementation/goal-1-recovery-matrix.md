## 风险、回滚与边界

交付丢失注入发生在真实事务complete之后，只改变调用方是否收到结果，不把它说成原生事务abort。旧指令同ID重试必须返回已有回执和最新状态，不能再扣物/返还或回退之后的进度。控制替换的put成功后abort/receipt配额失败需整个库记录逐字保留；修复后重复原意图验证一次结算。

Game文件导出不携带独立检查点，清除后不伪造CP；恢复当前Game完整字段并换runId，检查点缺失按页面原有说明呈现。正常路线不使用任何故障/边界夹具。Playwright WebKit不是Safari真机，模拟故障不是所有断电情形，数值仍未平衡；真人反馈与展示认可仍为T25。

每个缺口先有可复现反馈，再修并回归；新revert回退，不强推/删历史。测试产物/合法夹具只留临时目录与CI，不提交存档。最终本轮实际结果、失败/debug、SHA/PR与剩余范围执行后填写，T23候选包/生成器、T24/25仍未完成。
