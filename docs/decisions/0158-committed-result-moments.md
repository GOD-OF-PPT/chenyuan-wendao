## 本轮研究与缺口

本轮实际读取Riot [Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)：表现应传达玩法、注意力随重要性分配，并控制视觉噪声。实际读取[XAG114 UI context](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/114)：提供可理解的界面上下文，非玩家直接发起的上下文变化应通知玩家。这里用于结果层级与变化通知，不从来源推导2.4秒或本项目布局，更不宣称认证。

当前已有对象演出和结果通知，但通用反馈会过滤多数持续活动结果，部分重大结果仅短暂小字，完整规则结果没有形成稳定可读的游戏节拍。Q10三任务检查又实际证实过saved确认顺序吞掉局部演出，已先在Q10修复，不能把已有代码名当六类实机已通过。

## 六类交付

| 类型 | 真实内容与表达 |
| --- | --- |
| 抉择回响 | 原所选回应、人物/阶段和实际结果；用现有人物/场景承接，不能把EVENT待回应称抉择完成 |
| 每轮收获 | 修为、真实物资/灵石净变化与实际成本；轻量跳字和当前一条收获，不弹确认、不停下周期 |
| 突破定格 | 明确突破成功、前后真实境界及实际消耗；失败保持正式原因与原意图重试，不演成功 |
| 战斗胜利 | 正式battle_won后显示对手与真实掉落/消耗；普通一回合不称胜利，败退/撤离仍有原结果 |
| 成丹出炉 | 原配方成品、真实数量及成本，沿现有丹炉与成丹物件；不能按计划数量演成实际数量 |
| 结局画卷 | 真实收卷结尾与此生身份/境界/年月，现有天门、人物、卷轴承接；收卷后常驻可读，刷新只显示已结束状态 |

重大时刻可有约2.4秒的独立动效，动画结束后仍能读到本次主要结果与完整记录入口；普通轮次克制并合并到一处。不得同时再叠一份旧同类提示或遮挡实际按钮、费用、失败恢复。完整原记录仍可查，数据多时沿既有分页，不能截断成本或缩字。不得要求每轮领奖或关闭结果才能继续。

## 身份与边界

1. 仅消费已确认保存、同run/revision/command的正式观察与ActionResult；重放、重复通知、刷新、导入、恢复、其它页面同步及离线多周期不作为新奖励演出。Q10返回批次仍用已提交汇总，不把64+1尾批演成新单次收获。
2. 结果是只读表现，无Game写接口、奖励余额或新计时规则。未提交/保存待核对时不报成果；已提交丢回复在原意图重读后可读结果，但不得重复演出或再次授奖。
3. 一次只保当前结果；换人生/导入/恢复清除当前新结果身份。导航不能抢页/抢焦点或重新播放旧结果；原焦点/返回来源/错误重试继续成立。结局常驻状态与新结局演出分开。
4. 游戏内减动效及系统偏好均提供同样的静态结果与完整信息；不闪烁、不借动画结算、不用隐藏动效把结果一并撤掉。18px正文/14px辅助与44px入口继续保持。
