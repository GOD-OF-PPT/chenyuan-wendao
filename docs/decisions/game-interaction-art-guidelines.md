# 《尘缘问道》游戏交互与美术开发准则

调研与制定：2026-10-20（Asia/Shanghai）。来源是下列实际查阅的一手页面；规则中的单屏、配色、命令、读秒与工程数值是本项目已有决定，不能伪称外部行业统一要求。根AGENTS.md是开发执行入口。本文不代表用户已认可当前游戏，也不将无障碍专项等同认证。

同日用户追加决定以[放置定位与当前执行边界](0005-idle-clarity-no-compatibility.md)为准：放置长期积累与清晰主舞台优先；页面兼容开发和测试暂停。下列来源仍是设计参考，不构成恢复兼容矩阵的授权，也不证明放置成长已实现。

## 可执行规则与验收

| 规则 | 开发要求 | 必须提供的证据 |
| --- | --- | --- |
| G01 游戏舞台 | 场景/人物/当前动作建立主视觉；功能切换保留身份、状态和目标上下文。统一青黛墨绿、玉色操作、旧金边/关键进度。避免多层同等强调的卡片和重复标题；插画有明确场景或操作职责。 | 正常开场、修炼、取材、炼制、配装、事件、战斗、渡劫、结尾的整屏实拍；不能只交孤立插画。 |
| G02 一屏与完整信息 | 常用桌面主入口、当前决策、返回和翻页无需滚动。正文/配方/记录完整分类翻页；不裁切、不用嵌套长滚动或缩字掩盖空间不足。 | 实际高度/宽度、文本边界、按钮命中与所有目录项遍历，包含长文和保存/失败状态。 |
| G03 明确下一步 | 展示“目标—当前缺口—可达来源—下一步”。查看/选择/追踪与实际旅行、采购、挑战分清；不让满修为玩家继续无效吐纳。提示入口必须通向真实可执行步骤。 | 新档实走择法、筑基炼制/采购两路，逐次核对Game与引擎；查看全Game不变。 |
| G04 动作合同 | 真正行动前就近说明动作、消耗、效果、资格/禁用原因；主动作突出，次要入口降低强调。图标有文字，不靠悬停或颜色传达必要信息。 | 实际普通/选中/按下/禁用/焦点/错误画面与真实费用，不用写死演示数字。 |
| G05 六阶段反馈 | 输入即给按下反馈；受理后显示动作名/总耗时/递减读秒；截止后显示保存中；提交完成后才显示真实成功/变化；失败给原因与原意图重试。 | 保存前Game不变、真实倒计时递减、持锁事务到期仍无成功、失败/重试/过期和换人生测试。 |
| G06 持续结果 | 短光效结束后仍能读到主要实际变化和下一步，完整成本/停止原因可打开复看。摘要可选最重要的少量条目，必须标明其余变化并可查看；不要把短暂toast当唯一结果。 | 等光效结束后的可见结果/完整回执；刷新、重放、只读切页和外部新进度不虚报新收益。 |
| G07 表现层级 | 修炼/取材/交易/丹火/学习/配装/战斗/破境各有可辨反馈；普通动作克制，关键突破与天劫才用较强表现。效果不挡按钮、不抢焦点、不制造假伤害、掉落或隐藏概率。 | 真回执绑定、actual delta对照、最多粒子/原时长预算、减少动效后的静态结果与命中检查。 |
| G08 美术身份 | 场景、人物、敌方、天门阶段与真实Game对应；功能主题图仅作装饰，不冒充库存/装备。生产图无烘焙文字/数值/按钮，有来源、原稿、提示词、回执、alpha与导出hash。 | 当前ID→实际文件→真实页面使用链，完整解码、坏图/迟到回调、旧图留存与原资源预算。 |
| G09 可读性与层级 | 沿用现有正文18px、辅助信息至少14px、关键目标≥44px及既有可读性门槛。画作与正文分安全区；一个当前活动和主动作，减少重复标题、卡片与同时出现的提示。 | 当前固定1440×900桌面、单一Chromium的实际改动检查与整屏审图；兼容专项当前暂停，不运行字号/窗口/浏览器矩阵，旧缺口与断言保留。 |
| G10 流程可恢复 | 每境的修炼、关键物确定/替代获取、制作/购买、突破、恢复都能连续操作；普通突破真实消耗修为与物品。没有援助也可主线推进；零资源有合法恢复，失败不能锁死下一步。 | 正常新档、真实指令和全状态对照；不得靠导入节点/加物过关。核心卡点优先于装饰深化。 |
| G11 放置节奏与时间边界 | 放置修炼逐周期积累，当前活动/读秒/消耗/暂停/停止条件清楚；突破仍需筹备与主动确认，长批次不能共用短读秒跳过积累。旧25类动作短耗时是实现现状，不是放置节奏标准。查看、翻页、预览即时，不催读；离线与后台收益边界在对应机制实施前明确，不自动补发突破资源。 | 对当前改动验证真实周期、原子结算、暂停/恢复/刷新/过期/重复命令；虚拟时钟路线与真实节奏分别记，不把加速可达当成长平衡。 |
| G12 完成证据 | 需求、实现、自动化、远端提交、候选、节奏平衡与用户验收分开。完整矩阵保留声明与缺口责任；当前含兼容项的全量UI/性能执行和CI扩展暂停，取消/未执行不能标绿。 | 按当前授权记录固定环境功能证据；原最终门槛保留，兼容待用户后续明确恢复，真实试玩意见优先。 |

每次修改选择适用规则，先复现卡点，再做小闭环，最后核对这些规则与实际画面。每三个任务综合检查；整体完成仍依Goal1计划和真实用户复验，不以规则文档或机器绿灯代替。
