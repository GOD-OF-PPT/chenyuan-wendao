## 实施边界

1. 功能页采用一个连贯舞台：降低重复外框、内框和大卡片的同等强调，功能切换为清楚的书签/页签；标题只突出本玩法，位置/身份/活动常驻。对象画作保留自己的安全区，决定内容有实色或足够深的背板。保留全部入口、正文、分类/分页、预算展开和原有返回；不靠隐藏功能、内部滚动、裁切、缩字减负。正文18px、辅助≥14px、关键控件≥44px沿用。
2. 空丹炉用现有炉图和明确解锁说明组成完整场景，保留完整目录入口；展开后只读选中首个配方/器物，显示其材料/代价和实际禁用原因，不能再次留下空板；如增加下一步，只能查看当前目标/来源，不暗中修炼/旅行/用物。炼器用既有器物图符/器谱身份表现当前法宝，与丹炉区分；不画假掉落、假库存或额外法宝。复用已有生成原图与代码图符，若没有新栅格需求不重新生成重复素材。
3. 主要按钮、选中对象与按下/焦点反馈清楚，其余框线克制。调整短提示/封卷演出到内容安全区，不覆盖当前决策/返回/分页/导航；终局战斗庆贺只对应结果，不在已切换的新敌人上套胜利光环，收卷标题符合实际状态；短效不参与结算，持久实际成果和完整回执继续保留。问道与侧栏短反馈在亮背景可辨。恢复待核对合并近义提示，但真实新确认CAS、原意图重试、错误与禁用行为不变。
4. 只修当前提示优先级：化神已齐物但受伤时先查看完整准备/恢复，再明确行旅；近期取材/采购/炼丹回执不能压过当前恢复或圆满阶段；其他既有剧情、战利品与配装指引保持。预估/查看即时且不改变Game/活动，不自动接下一玩法。其他全境路线比较/总时长提示留B，不在本项加管理台。
