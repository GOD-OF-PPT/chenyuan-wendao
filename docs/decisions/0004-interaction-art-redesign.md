# ADR-0004：依据实际验收重做交互层级与整体美术

2026-10-18，来源为用户在本聊天的直接反馈，原话见[Goal 2输入](../../goal-2/input.md)。

用户指出当前交互不清晰、游戏画面效果不佳，已经损害可玩性与吸引力，并授权设定目标、使用imagegen优化整体交互和美术资源。这是Goal 1 T25收到的负面验收，不是最终展示通过。

沿用新国风半写实方向，但旧版已经技术通过的布局与美术可调整。按[Goal 2计划](../../goal-2/plan.md)先整理现场证据与目标稿，再落实主要操作、状态与目标层级，独立场景、统一人物/敌方、完整成长/战斗/故事/终局流程，最终重新交用户验收。

桌面角色/主舞台/目标的三栏职责保留，可调整密度、宽度和装饰；手机单独设计，以当前决策优先。原四场景共享裁切的资产预算保留为历史，本轮七场景与九敌方视觉另建清单并扩展核验。目标稿不得作为整图热区或替代实装。

物品/数值/选择控制成长、约30分钟只观察理解、原子存档、旧档/恢复与功能完整性继续成立。数值仍未平衡。规则模块和存档格式不因美术改版任意变化。v0.3正文及既有素材、回执、旧候选均保留，不自动合并、部署或发Release。
