## 玩家会得到什么

剑、符各三槽的升级功法增加一个替代分支：合计18卷、每派每槽两条升级路，同一人生同组只能掌握其一，基础卷始终可用。切修法不能抹掉既有选择或绕过互斥；查看不选路，正式研习完成才落定。互斥队列须在受理前指出冲突，不先收费学一半。原升级路保留，替代路承担清楚的代价。

| 槽位 | 原升级路 | 替代路候选 |
| --- | --- | --- |
| 剑心 | 止水剑心：静修与护体 | 破妄剑心：直伤提升，放弃止水的静修/护体收益 |
| 剑势 | 听雨剑势：护体、较少剑意 | 惊涛剑势：耗灵更高的双层攻势，无随招护体 |
| 剑终结 | 回风归一：较低爆发、回血 | 断岳斩：耗灵更高，可破护阵与重压，放弃回血 |
| 符心 | 太清符心：静修与回灵 | 清虚符心：净受伤减免，放弃太清的静修/回灵收益 |
| 符起手 | 寒霜符：长符印 | 烬火符：更高耗灵/灼伤、更短符印与较弱护体 |
| 符终结 | 归元符：收印回灵 | 裂阵符：耗灵更高，可破护阵与重压，放弃回灵 |

法宝首次装备免费，已装配另一器后转换须明确确认真实投入，候选24灵石和1灵露。费用在比较及确认前可见，缺量给可达来源；不暗扣、不假等、不因刷新/丢回复再收费。灵露和现金均已有确定来源，不能将转换变为主线资源死锁。同器重按仍无变化且不扣费。

符修得到正式的重击应对：已有符印时择机引爆可断势；预判策略会在蓄势阶段按符印余量续符或护持，重击才引爆。需要实际灵力和原预算，不能凭策略标签免除消耗。剑修仍按真实满剑意破势；两派基本护体、回灵、用药和撤退始终可用。

## 敌人和问心

三个后期敌人有不同的可预判机制：剑傀有直伤反震阶段，护体/持续灼伤可应对；心魇按造成的实际净伤害回血，减伤与爆发影响其恢复；守灵有护阵与不可寻常打断的重压，护体、破阵终结、补给或避战均是可行选择。护阵只减直伤，持续符印另算；反震按实际直伤且有上限，即使击破敌人也须结算，气血耗尽按正式败退处理，不同时发战利品。普通敌人修为仍为0，三种关键物来源及采购/炼制替代保留。

具体阶段、比例、初始225重压等须在本轮实测；至少证明一种没有充分筹备的后期默认安排确实触及危险/用药/撤退边界，并有已知对策可改善，不能只让九个敌人共用一种节奏。强效果要事先说明，基本应对不能只留给某个付费或互斥分支。预判开关会明确说明应对蓄势/反震/护阵；关闭后尊重原优先级与安全停手，不强加完美操作。

问心的两回答保原确定选择与已有数值倾向，但第三关另有不同的实际阶段：接纳有镜照反震期，放下使重击节奏提前。选择前说明差异，实际意图与正式结算共用同一份机制，不能只换文案。仅当前敌人/关卡可放置，问心、下一关与收卷仍待玩家决定。
