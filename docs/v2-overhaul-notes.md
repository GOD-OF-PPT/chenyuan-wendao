## 2. 全流程趣味性与策略深度进化
1. **天时星象流转（`CELESTIAL_OMENS`）**：
   - 每 24 个游戏月自动流转五大天象（`灵潮涌动`、`紫微临丹`、`百草丰年`、`贪狼破军`、`万宝云集`），动态影响吐纳修为、炼丹产出、秘境奇遇、战斗灵石与赌石爆率；亦可在顶栏花费 20 灵石主动【观星推演】改换天时。
2. **三才冲脉·天道破境仪式（Interactive Meridian Breakthrough Rite）**：
   - 境界圆满突破时开启交互式冲脉灵针仪式：把握太极丹田金区定脉可铸就【天道一品·无瑕道基】（全属性永久乘区 `+12%`，并触发 **4 选 1** 天道法则赐福），稳守青区亦可得【地道上品·稳固道基】（全属性永久乘区 `+5%`）。
3. **【起-承-绝】三段武学连携 &【凝气御守·完美拆招】**：
   - 战斗面板实时追踪最近三式出招，触发【天外飞仙】（`平斩→起势→终结`，终结技 `+45%` 伤害并回灵降剑雨）、【九宫焚天】（`起势→御守→终结`）或【法天象地】（`任意二式→神通/合击`）。
   - 当妖兽蓄力预告重击时，选择【凝气御守】可触发【完美拆招·借力反斩】，化解约 80% 重击伤害并反震妖兽、夺回灵力节奏。
4. **五层连线分支秘境星图（Interactive SVG Constellation Map）**：
   - 秘境探索升级为可视化 SVG 星盘连线拓扑图（`入阵口 → 仙草谷/古剑冢/护宝妖/云游商/问心泉 → 终层法则台`），支持自由择路推进与灵识采集奇遇暴击。
