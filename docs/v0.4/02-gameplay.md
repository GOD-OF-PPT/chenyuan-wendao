# 玩法与流程修订

这是待实施规格，保留v0.3的用户约束。关联[D01—D09](01-competitors.md)。不设首局通关时长；30分钟仅是第一次可用性观察窗口。

## 1. 三层循环

**单次决定**：阅读情境或敌方意图 → 看已知成本 → 选择 → 原子保存 → 文字/数值一起反馈。

**一个目标**：选定突破、功法或法宝 → 查看缺口 → 取材/委托/战斗/采购 → 制作或研习 → 实际装备/使用 → 看到能力变化。

**修仙人生**：持续积累 → 境界变化 → 旧地点和人物产生新回应 → 整理渡劫准备 → 问心/雷劫/开天门 → 生平结尾。退出后继续原档，不要求重开才有价值。

## 2. 首次体验按行为揭示

| 状态 | 主要操作 | 显示的信息 | 进入下一状态的条件 |
| --- | --- | --- | --- |
| 新档 | 填道号、入破庙 | 角色身份、唯一回春丹、存档入口 | 创建存档成功 |
| 破庙 | 赠丹/交易/自保 | 已知即时成本；不剧透全部未来 | 选项实际结算 |
| 初次修行 | 前往洞府、吐纳 | 单次收益、修为上限、游戏月 | 玩家自行积累并引气 |
| 选择修法 | 剑修或符修 | 基础行动与资源差别 | 装备一组基础功法 |
| 第一个自选目标 | 筑基筹备/学术法/尝试历练 | 材料用途和来源 | 玩家自选，不强制战斗 |
| 自主游玩 | 重复既有循环 | 可以关闭引导，随时重新查看 | 不要求规定境界或时刻 |

开场赠丹只改变道具和因果，不赠境界。交易的剑简增益不能仅让剑修独占最佳开局；将其用途说明为当前剑法收益，并在后续提供等价的研习选项，具体补偿方式需经济回放而非凭感觉发资源。三种开场必须都能学会两类基础修法。

首次观察应能验证玩家理解：修为不是唯一门槛；材料有用途；行动消耗游戏时间；可以换装改变战斗；下一步能从目标找到。理解慢不惩罚、阅读久不扣寿元。

## 3. 当前目标卡（D02）

只置顶一个主要目标，允许手动替换；其他机会作为最多两条小提示，不堆红点。默认建议下一突破，但玩家可选择一门术法、一件法宝或一段已出现的仙缘。目标选择是界面偏好，不消耗游戏年月，不改变战斗或奖励。

以“筹备筑基”为例：

> 修为 700 / 1000；筑基丹 0 / 1。
> 获取方式：自行炼制 / 坊市购买。
> 炼制缺口：凝气草2、灵露1、妖核1；还需灵石20。
> 妖核来源：山野斗法（有战损） / 宗门护送（确定） / 坊市购买（50灵石）。

每行来源显示可达性、产出、成本与前往按钮。未达境界显示真实条件，不让玩家为下一境界物资反过来先突破。点击前往后保留目标，取材完可回洞府，不自动替玩家执行采购或合成。

计算缺口：`max(需求数量 - 可用库存, 0)`。普通物品无容量限制；即使追踪某配方，也不暗中锁定所有材料。使用会影响追踪目标的稀缺材料时给轻量提示，不反复弹确认。

本轮仅做来源比较，不承诺多目标全局最优。经验、存款和副产物会改变路径；显示确定值和风险来源，不能编造成功率。

## 4. 三种筹备路线（D03）

稳妥路线：采集与宗门委托，少耗补给但占游戏年月。冒险路线：战前可看敌人意图机制，通过战斗获得同类关键资源；收益须连同战损和疗养估价。采购路线：用已有灵石或委托积累购买材料/成丹，减少取材步骤但挤占功法和辅助修炼预算。

这三种路线不是职业锁定，玩家随时混合。成丹可买是保底，不应为了展示战斗强迫所有普通突破打Boss。终局渡劫保留必须参与的可恢复挑战。

安全重复操作支持1次/若干次/达到目标；上限50次只是单批安全边界，不是修为赠送。预览明确最多花多少、何时提前停。资源不足、修为满、目标完成、寿限或需要选择的事件出现时停止，已经成功步骤保留，未执行步骤不扣费。复用现有批次规则，不加入现实定时器。

## 5. 历练流程（D06）

行前准备卡列出目标资源、补给、当前功法与已知敌人机制；之后进入一个现有事件或战斗；归来卡说明获得物资、净损耗、是否接近目标。三段是同一套既有页面状态，不另造行动点、体力币或副本层数。

险境只用可解释风险：例如“下一次重击基础32”“本回合符印剩余两次”。撤退无战利品、已消耗丹药不退；普通败退保留功法与未消耗库存，回洞府可疗养。结果说明具体失误与可调整项，不只说战力不足。

| 境界 | 主要筹备问题 | 本阶段有意义的变化 |

| 凡人 | 学会积累 | 相遇与引气，认识行动成本 |
| 炼气 | 补给还是突破 | 两个基础修法与三种取丹路线 |
| 筑基 | 当前突破还是长期效率 | 地脉灵玉，术法替换与学习成本 |

| 元婴 | 安全、效率与人情 | 凝魂资源、关键人物承诺与后续回响 |
| 化神 | 整理全部准备 | 道蕴、渡劫引、换装、补给、可选援助 |

内容上限延续当前工程：6地点、12功法、4法宝、4NPC。材料以现有7种为整合上限，2种恢复丹与5种突破/渡劫消耗物；这比早期3材料预算扩大，但已在审计代码中存在，本轮不再追加。其用途在经济文档解释。

## 7. 因果不能退化成免费领物（D05）

现有事件仅用前置事件ID判断，不能充分区分之前选择；必须增加“选项条件/变体”，且失败条件不能困死主线。`requires`表示见过，`condition`表示如何选择，两个语义分开。

沈清禾示例：赠药者重逢收到感谢并获得一份相助；交易者得到履约交易的机会；自保者首次正式认识，以另一次有成本的帮助建立新关系。三条都可到渡劫，不能重写成所有人都曾救过她。终局可有援助优势，但无援助也必须能靠正常物品/搭配成功。

裴照示例：同行/竞争改变重逢台词与当次交易；后期盟约可重新选择，但应承认过去发生过什么。拒绝早期合作后不能直接被称作多年盟友。

事件总预算36：开场1、主要人物节点11、行旅见闻18、机缘6。替换现有文本，不额外增加同量内容。18条见闻至少包含交换、救助、筹备建议、路线取舍、旧地回访等不同模板；单纯免费领取只算奖励，不算有意义的选择。

## 8. 渡劫与续玩

启动检查：化神修为满、渡劫引、合法修法、正确地点、没有未决事件。保存启动前检查点和扣物、进入问心必须在同一事务中。检查点位于存档槽外侧，不能递归嵌入自己。

问心可选择承受更稳或进攻更强，两者无隐藏道德必败。随后三关复用战斗规则，气血灵力跨关保留；中断后恢复同一意图，不重抽。失败提示已消耗物与恢复方法；恢复到完整准备快照，不单独返还道具，且检查点在被新检查点替换前可重复使用。

飞升结尾从openingChoice、choices、milestones、修法和法宝生成。滚动日志只保留最近信息，不作为唯一生平数据。主动归隐和寿尽必须有不同原因，不把十八岁主动退出写成寿终。

重新进入优先显示原档境界、追踪目标、上次重要结果和继续按钮；无离线惩罚、签到或每日任务。第二局用于不同修法与因果，不采用永久数值继承逼迫重复。
