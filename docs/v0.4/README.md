## 文档关系与本轮边界

v0.3 原文保持不动，作为已认可历史基线。v0.4 是按最新调研要求提出的细化方案；不改变用户明确约束，新交互和调参项均须实现及验收后才能标为完成。代码事实以审计提交为准；设计提案不能反过来证明代码存在。

本轮不改运行代码、依赖锁、CI权限或仓库可见性，不合并旧PR、不部署站点、不新增多人/支付/在线AI。不复制竞品代码、台词、截图或素材。未来实施先更新 Issue #3—#8 的证据状态，避免把旧绿色测试当作新全流程验收。

**优先顺序：统一网页/规则/存储入口 → 全境界可操作与目标追踪 → 因果分支及渡劫恢复 → 正式美术 → 候选版与真人反馈。**

可运行本轮资料检查：`python3 docs/v0.4/tools/check_documents.py`。该命令只检查文档内部链接、配置样例和静态算例，不能代替游戏测试。
