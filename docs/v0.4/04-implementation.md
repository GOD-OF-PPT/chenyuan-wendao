# G1—G5实施修订：先接通，再丰富

基于2026-10-13审计快照。阶段仍关联 Issue #4—#8；本轮只完善文档，不关闭阶段。方法依据：[npm锁定安装](sources.md#s10)、[IndexedDB事务](sources.md#s11)、[浏览器测试](sources.md#s13)。

## 1. 当前真正的关键路径

`G1复核 → 单一正式引擎与存档迁移 → G2全境界网页接入 → G3条件因果/渡劫恢复 → G4实装视觉 → G5候选版与真人反馈`。

美术拆分、事件改写、测试设计可并行；最终验收必须回到同一版本。已有`src/full`不要再复制成第三套规则，旧`src/game`作为兼容/历史测试基线，正式网页只使用一种引擎。

角色分工：规则开发负责内容与迁移契约；前端开发负责Store/交互/持久化适配；策划负责目标、数值和文案；美术负责场景/肖像/组件；测试可由开发交叉执行，真人反馈单列。未指定真实人员，不虚构负责人承诺。

## 3. 统一查询、指令和持久化

组件读取`GameViewModel`和纯查询结果；所有资源变化仍经`Command {commandId,runId,expectedRevision, ...action}`。UI不能直接加物品/境界。成本预览调用同一规则计算但不提交、不推进随机状态，不能由前端另写一份公式。

`runId`隔离人生与导入；`revision`防旧页面覆盖；同ID同请求返回已提交结果，同ID不同请求拒绝。选目标/字号等显示偏好可单独保存，不因查看资料改变游戏年月。广播只提示重新读取，不能替代事务冲突检查。

同一readwrite事务内完成读取当前状态、查回执、校验、状态/回执/必要检查点写入。事务内部不能跨网络await；完成事件之后才发布成功。失败保留上一次好档与错误提示，不因重新加载好档把“本次操作失败”改成成功。[S11](sources.md#s11)

IndexedDB的complete不代表所有断电场景永久落盘；导出备份和配额错误提示仍是必要保护。[S11/S12](sources.md#s11)

## 4. 存档迁移与恢复策略

保留原DB原记录，只在副本上识别旧M1、Adventure与full格式；先校验旧格式，再确定映射，再校验新格式，全部成功才替换。未来版本拒绝导入并给出备份提示，不清空重开。内容版本与结构版本分别校验；数值更新需要兼容政策而不是静默升级。

明确修复旧适配器硬编码的事件实例：导入后应为`newRunId + ':' + activeEvent.id`，不是全部写成`:temple`。迁移不虚构已经帮助的NPC、不免费赋予高阶物品。无法无损映射的战斗状态先保留旧档并告知限制，不擅自当成战斗胜利。

检查点至少覆盖普通突破前和START_TRIAL前；保存时绑定schema/content/balance与来源runId。恢复是完整快照替换并生成新runId/清理旧回执，不能只回退境界或复制奖励。恢复后仍保留可复用的准备检查点，防止第二次渡劫失败无路可退。

## 5. 确保测试验证的是正式网页

全流程E2E必须从网页新建存档开始，手动等价点击到飞升；不调用测试API直接发材料或境界。可用纯引擎提前生成合法演示档，但独立于正常路线验收。

生产构建后启动preview再测试，未构建旧dist必须报错或先清理；`reuseExistingServer`在CI关闭。Playwright显式定义chromium/firefox/webkit项目；只安装二进制不能算覆盖。WebKit不等于Safari真机。[S13](sources.md#s13)

建议PR快速门禁跑规则、类型与Chromium关键路径；候选版跑24路线×3引擎及恢复矩阵。降低耗时应分层或拆分job，不跳过失败断言。重试成功作为不稳定用例记录，不抹掉首轮失败。

## 6. 构建与交付命令

现有G1分支应复核以下命令（本次未重新执行游戏构建）：

```sh
npm ci --ignore-scripts
npm --prefix web ci --ignore-scripts
node scripts/check_lock.mjs
npm run typecheck
npm test
npm run replay
npm --prefix web run build
cd web
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
```

全境界/跨浏览器测试是否真正执行取决于接入与配置，不能只复制这段命令宣称完成。运行包通过localhost HTTP服务测试，不用file://。Vite base设置需覆盖根目录与计划子路径；preview只作本地验收，不擅自部署。[S14](sources.md#s14)

产物清单包含commit、schema/content/balance、Node/npm、锁文件hash、测试结果、dist校验值和已知问题。相同依赖锁不承诺不同OS二进制一致；候选包以实际构建文件的校验值识别。临时Actions附件不是长期唯一交付；授权发布后再建版本化Release，本轮不发布。

## 7. 范围削减顺序

需要压缩成本时先减少普通见闻和装饰层，再减少备用法宝；不能砍掉资源保底、目标来源、两修法的行为差异、原子存档和可恢复渡劫。所有阶段都以“能运行的纵向流程”递交，而非继续堆未接入模块。
