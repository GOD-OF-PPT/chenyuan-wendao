# 验收、试玩与完成证据

本章全部是待执行验收要求，除[差距审计](07-repository-audit.md)标明的历史证据外，不声明G1—G5完成。规格依据[S13](sources.md#s13)、[S15](sources.md#s15)，趣味目标是本项目假设。

## 1. 两种“完成”分开

工程候选版：同一SHA的锁定安装、类型、规则、生产构建、全流程、恢复、布局及产物校验通过，阻断/数据损坏问题清零。

展示验收版：工程候选版基础上，目标玩家能理解玩法、有记忆点，用户确认美术与演示效果。没有真人反馈时保持“待反馈”，不能因为程序走到飞升就关闭G5。

## 2. 覆盖矩阵

| 层级 | 最少覆盖 | 主要断言 |
| --- | --- | --- |
| 配置 | 所有境界/配方/来源/技能/法宝 | 引用有效、关键物可达、无正收益采购循环 |
| 规则 | 突破/合成/战斗/事件/结束 | 前置失败不扣物、奖励一次、不同修法真实不同 |
| 主路线 | 3开场×2修法×2筹备路线×2成功结尾=24 | 从正常新档到飞升，不免费改状态 |
| 构筑 | 12技能每效果、4法宝每效果 | 装备条件、生效范围、回合时序、数值预览一致 |
| 因果 | 每重要选项及后续变体 | 不错误称呼旧关系；无援助可飞升 |
| 存档 | 旧M1/Adventure/full、各未决状态 | 迁移、重复指令、多标签页、断事务、配额失败、坏档、未来版本 |
| 终局 | 问心及三关间退出、二次失败恢复 | 不重抽、不重复结算、不丢准备检查点 |
| 浏览器 | Chromium/Firefox/WebKit实际项目 | 24主路线每引擎运行；单引擎绿灯不能替代 |
| 交互 | 四尺寸、键盘、文字放大、无背景 | 按钮可达、状态可读、焦点正确、无重叠 |

两条筹备路线为稳定取材炼制与主要靠采购；均可学习必要技能和准备补给，不能把后者误写成“零战斗飞升”。无盟友只做必要覆盖，不与每项排列组合相乘。极端穷困、寿元边界和法宝各效果用独立用例，不靠24条正常路线代替。

单元测试可构造边界状态；全流程测试不得用同样手法跳过资源系统。测试数量只说明执行量，未连到正式UI的引擎测试不能证明网页全流程。

## 3. 关键恢复场景

同一指令连续提交、提交成功但页面未收到结果后重试、同ID不同内容、旧revision、多标签页先后写入、导入过程中失败、非破庙事件导入、战斗中导入、版本升级时旧tab未关、事务abort、存储不足、无存储权限、第二次恢复检查点。每项都记录错误码、好档是否保留、资源是否变化与实际UI状态。

读取失败不能静默开新档。恢复成功必须从保存的完整状态开始，不用“返还丹药”猜测如何回滚。只确认事务逻辑和已测浏览器行为，不承诺硬件断电永不丢失。[S11/S12](sources.md#s11)

## 4. 约30分钟真人观察协议

建议先找6—8名目标玩家做定性观察，含熟悉修仙与不熟悉系统的人。样本量是工作安排，不是统计功效证明。先说明正在测试游戏而非玩家，征得记录同意；不收真实姓名、聊天全文或无关个人数据。

开场仅说“按你喜欢的方式修炼，遇到疑惑说出来”。不规定到达筑基。约30分钟时记录是否能解释五件事：修为如何获取、材料用途、突破缺口、至少一个资源取舍、两种战斗选择为何不同。未进入战斗的玩家可给独立合法体验档观察操作，但该段不得算正常新档流程。

记录表：匿名编号、提交SHA、是否熟悉题材、目标选择、首次找不到下一步的位置、无意义重复、一次战斗决策、记住的因果、继续游玩的具体目标。原始观察与设计解释分栏，不用“他觉得不错”替代证据。

候选判断目标：至少约75%的本轮样本无需主持人代操作就能说明主要目标与物品缺口；出现连续3次相同无新信息点击的地点优先检查；至少一半能说出一次有因果的选择。比例只是小样本迭代门槛，不外推市场留存，未达标先修流程而非添加系统。

## 5. 实验与修订顺序

H1目标来源卡：对比改版前后同等新手是否找到缺失物资，记录主持人提示次数。H2构筑差异：用相同敌人观察剑/符是否选择不同动作，并能解释。H3因果：在发生回响后询问“为什么此人这样回应”，检查是否记住先前选择。H4长期目标：结束观察时询问下次想继续什么，而非只问要不要推荐。

不要让同一玩家先学会旧版再测新版并当成无偏A/B结论。小样本以发现问题为主；记录版本、顺序与学习效应。回归修正后用新参与者再验证主要堵点。

## 6. 交付清单与验收记录

每阶段Issue填写：实现SHA、PR、验证范围、实际命令、通过/失败/未执行、CI链接、产物hash、截图、剩余风险。候选包增加运行说明、变更/存档兼容说明、已知问题和合法演示档生成方法。

门禁不接受“旧提交83/17通过，所以新增飞升也通过”。截图生成不等于美术认可；安装三浏览器不等于三引擎执行；锁定依赖不等于没有安全问题。关闭阶段需完整证据，最终发布与合并仍由用户授权。
