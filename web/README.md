# 尘缘问道 · 可运行测试版本

G1 锁定分支继承 M1 可玩范围：凡人 → 炼气 → 筑基。含两种修法、四个地点、交易炼丹、真实浏览器存档。不是完整飞升 Demo。

约 30 分钟仅是基本玩法理解目标，不固定筑基或通关时间。所有数值为未平衡初值；游戏内年月随行动立即结算，阅读与离线不耗寿元。

## 从源码启动

推荐使用已验证的 Node.js 22.16.0。在仓库根目录执行：

```sh
npm ci
npm --prefix web ci
npm --prefix web run dev
```

打开 `http://127.0.0.1:5173`。默认仅监听本机。不需要 API Key、数据库服务器或账号。

## 运行已构建版本

[已验证的 Actions 运行](https://github.com/GOD-OF-PPT/chenyuan-wendao/actions/runs/38367640849) 内提供 `chenyuan-playable-dist` 附件。下载解压后，在含 `index.html` 的目录执行：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080`。不要双击 HTML 使用 file://。构建包自含脚本和背景，不依赖 CDN，也不含字体文件。这是本地运行包，不是公开试玩地址。

## 执行测试

从仓库根目录执行：

```sh
npm run typecheck
npm test
npm run replay
npm --prefix web run build
cd web
npx playwright install chromium
npm run test:e2e
```

Linux 缺少系统库时使用 `npx playwright install --with-deps chromium`。测试自动启动生产预览服务器 4173，不需要另开 dev。

## 首轮试玩路径

1. 输入道号，选择赠丹、交易或离开。每条路线都能继续。
2. 返回洞府，自然吐纳至修为满，确认引气入体。
3. 选择剑修或符修，进入历练页前往山野。
4. 采药、凝露；妖核可通过战斗、宗门护送或采购获得。
5. 在洞府的行囊页炼制筑基丹，或者在坊市直接购买。
6. 修为圆满后确认突破，实际消耗筑基丹。缺材料或修为时不能突破。

也可先做宗门杂务挣灵石，完全不战斗地购买成丹。以上是测试路线示例，不是强制操作顺序。

## 战斗要点

剑修通过青锋起势与普通攻击积累剑意，惊鸿斩消耗剑意；满三层可以打断敌方当前回合的重击。符修通过镇灵符造成持续灼伤，再以燃符诀提前结算剩余灼伤。

普通攻击回灵 6，护体回灵 5、减伤 24。使用丹药占一回合。失败保留功法与物品，回洞府后可免费疗养；撤退最多损失 8 气血，不取得战利品。

两种修法当前是固定技能组合，尚不是全部 12 功法的自由搭配系统。

## 存档与恢复

每条指令在 IndexedDB 事务完成后才刷新角色数据。事件、战斗、奖励、修法与经历一起保存。设置中可导入、导出、恢复最近一次突破前检查点或重新开始。

坏档不会覆盖当前存档。替换或恢复会产生新的 runId，旧标签页不能覆盖新人生。支持导入上一阶段 M1 经济 JSON，不额外赠送资源。

不同地址、端口和浏览器的存档不共用，可通过导入导出迁移；清理浏览器数据可能丢档，建议导出备份。本版没有服务器同步，也不提供反作弊保证。
