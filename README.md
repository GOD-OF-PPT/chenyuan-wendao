# 尘缘问道

古风文字修仙网页 Demo · 从凡人修士到飞升。

**约 30 分钟了解基本玩法，不限定通关时长。成长由物品、数值、功法搭配和选择决定，不按现实分钟赠送境界。**

## 当前状态

设计基线已提交 main。此开发分支新增 **M1 首境界经济规则原型**：开场选择、稳定取材、交易、炼丹、修炼、消耗物品突破，以及输入和状态校验。

**尚无可玩网页**，未实现战斗、正式界面、浏览器存档或飞升。MemorySession 仅验证内存会话，不等于 IndexedDB；数值版本 m1-unbalanced.1 为未平衡初值。完整边界见 [M1 实施记录](docs/implementation/M1-economy-core.md)。

本地重新验证：类型检查通过、65/65 规则测试通过、3 开场 × 2 确定经济路线到筑基。此结果不代表远端 CI 或完整 Demo 验收；Actions 结果以对应提交为准。

## 运行规则测试

需要 Node.js 22.16 或更新版本：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run replay
```

没有网页开发服务器入口。回放输出是游戏内年月与资源收支，不是要求玩家在现实中等待。CI 只测试、不部署，后续代码通过功能分支与 PR 管理。

## 约束

规则与 UI、存储分离；当前所有行动必须校验 commandId、runId 和 expectedRevision。正式持久化完成前不宣称存档可靠性。成长不读取现实时间，关键物资有确定来源；炼气至筑基同时检查修为与筑基丹并真实消耗。

仓库由项目负责人创建，接入时为 public，未修改可见性。未复制参考项目代码，未提交凭据、字体或个人存档，未擅自添加开源许可。不强推、不自动合并、不部署公开试玩站点。

资料子集校验：`python3 scripts/check_docs.py`，不代表游戏或全素材归档检查。
