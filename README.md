## 开发约束

规则、内容、存储与UI分层。普通突破验证修为并真实耗物；关键物资有确定且可达来源；阅读和离线不耗寿元。动态文字、按钮和数值必须是网页元素。新功能经功能分支和PR递交，不强推、不擅自合并、不公开部署。

新文档检查：`python3 docs/v0.4/tools/check_documents.py`。原资料子集检查：`python3 scripts/check_docs.py`。这些资料检查不代表游戏、数值平衡或真人试玩验收。
